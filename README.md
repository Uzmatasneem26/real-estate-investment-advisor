# Real Estate Investment Advisor: Predicting Property Profitability & Future Value

A Streamlit real-estate analytics project using the supplied `india_housing_prices.csv`.

## Features
- Interactive overview dashboard and property explorer
- Dataset cleaning and feature engineering
- Baseline Random Forest classification and regression pipelines
- Investment screening using a clearly disclosed proxy target
- Five-year value scenario based on a user-entered annual appreciation assumption
- Model evaluation metrics and optional MLflow experiment logging
- CSV download for filtered properties

## Run locally (Windows PowerShell)
1. Open this folder in VS Code.
2. Create and activate an environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
3. Install packages:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
4. Clean the data:
   ```powershell
   python scripts/data_cleaning.py
   ```
5. Train models:
   ```powershell
   python scripts/train_models.py
   ```
6. Run Streamlit:
   ```powershell
   streamlit run app.py
   ```
7. Optional MLflow tracking:
   ```powershell
   python scripts/mlflow_tracking.py
   mlflow ui --backend-store-uri ./mlruns
   ```

## Data cleaning notes
- The original upload contains 250,000 rows and 23 columns.
- No missing cells or exact duplicate rows were found in the uploaded CSV.
- `Price_per_SqFt` is recalculated as `Price_in_Lakhs * 100000 / Size_in_SqFt`.
- `Age_of_Property` is recalculated as `2026 - Year_Built`.
- Rows with invalid critical values are removed; missing numeric values are median-imputed and missing categorical values are marked `Unknown`.
- A `Amenities_Count` feature is added.

## Important modelling limitations
The supplied dataset does not include observed rental yields, realized investment returns, or actual prices five years in the future. Therefore:
- `Good_Investment_Proxy` is a rule-based demonstration label based on relative price within a city, public transport access, amenities, and property age. Classification metrics evaluate this proxy label, not real investment success.
- The regression model predicts current listed price (`Price_in_Lakhs`). The five-year estimate applies a user-selected compound annual appreciation assumption to the estimated current value. It is not a model trained on actual five-year outcomes.
- Predictions are educational estimates and not financial advice. For a production-grade advisor, obtain historical sales/returns and validate out-of-time.

## GitHub and deployment
Commit the source and data files as appropriate. For Streamlit Community Cloud, choose `app.py` as the main file. Large datasets can make repository deployment slow; consider Git LFS or external data storage if needed. Keep generated `mlruns/` out of Git.
